## Overview

GeoShield is a full-stack web application that evaluates cybersecurity risks based on a user’s geographic location and surrounding environment.  
It helps users identify unsafe networks, phishing-prone areas, and insecure public Wi-Fi, and provides real-time security recommendations.

---

## Key Features

• Location-aware cyber risk analysis  
• Risk scoring (0–10) with detected threats  
• Environment-based analysis (Cafe, Airport, Mall, Public Wi-Fi)  
• Secure JWT authentication  
• Protected routes and role-ready architecture  
• Real-time security dashboard  
• MongoDB-backed persistence
